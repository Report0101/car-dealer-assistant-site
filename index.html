Car Dealer Assistant

A private assistant that helps Le Hoang review car dealer replies, collect vehicle information and coordinate viewing appointments against Google Calendar.

What it does

The assistant uses an authorized Gmail connection to detect new mail and review relevant dealer conversations. It records vehicle details, missing information and appointment proposals in a private database. Google Calendar helps check availability.

The current deployment runs in dry-run mode: it records proposed actions for review. Automatic dealer email and appointment changes require separate, explicit activation. The assistant cannot buy a vehicle, make a deposit or accept a contract.

Google account access

Access is granted through Google's OAuth consent screen. Gmail's IMAP connection requires the full-mail permission, although the application opens that connection read-only and implements no mail deletion. Calendar event access supports scheduling and explicitly authorized tests.

This website provides public application information only. It has no Google sign-in form, account credentials, inbox content or private dashboard data.
