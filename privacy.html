Car Dealer Assistant

Privacy policy

Effective 7 September 2026

Car Dealer Assistant is operated by Le Hoang for personal car-shopping administration. It is not offered as a public account service.

Information accessed and stored

With the account owner's OAuth authorization, the service accesses Gmail mailbox changes, relevant dealer messages and their conversation context, sender and subject information, and Google Calendar events needed to check appointment availability. It stores relevant message content and identifiers, vehicle information, scheduling details, proposed decisions and audit records in a private PostgreSQL database. Application logs may include relevant decision summaries.

IMAP requires Google's full-mail scope, which technically permits reading, composing, sending and permanently deleting mail. The application uses IMAP read-only, implements no deletion action, and gates email sends separately. Calendar event permission allows reading and editing events; real appointments are changed only within the separately approved automation policy. Dedicated test events may be created and cleaned up during authorized acceptance testing.

Purpose and sharing

Google user data is used only to provide the owner's requested dealer correspondence, vehicle review and scheduling assistance. It is not sold, used for advertising or used to train general-purpose AI models. Authorized operators may inspect relevant records to maintain and test the service.

Railway hosts the worker, database, secrets and logs; the deployment currently uses its US East region. Google processes Gmail and Calendar API requests. GitHub Pages hosts these public information pages and may process visitor connection information under GitHub's privacy policy. Private mailbox data and OAuth credentials are not published to GitHub Pages. If the owner enables an external notification provider such as Telegram, selected relevant alert content will be sent to the owner's configured destination.

Credential protection

OAuth credentials are stored separately from public source and website files and are excluded from application build uploads. Google connections use TLS; database traffic uses Railway's private network. Credentials are not intentionally written to application logs. This website does not collect Google passwords, OAuth tokens or mailbox content and uses no analytics or tracking scripts.

Retention, revocation and deletion

Private records are retained until the owner deletes them; no automatic retention schedule is currently configured. The owner can revoke Google access at any time through Google Account security settings. Revocation stops future authorized access but does not erase already stored records. To request deletion of stored records and credentials, contact Le Hoang using the address below. Service-provider logs and backups remain subject to their applicable retention controls.

Google API limited use

Car Dealer Assistant's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.
